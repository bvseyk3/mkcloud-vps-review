## Mkcloud 是什么：先说清楚它的定位

Mkcloud 是一家 2023 年成立的国内商家，主营**合规跨境电商专线服务器**，产品覆盖广港 IEPL、沪港 IPLC、沪日 IPLC、沪美 IPLC、IX 上云互联专线，以及厦港/泉港高防和上海 CN2 等线路。

它卖的不是普通 VPS。普通云服务器比拼的是 CPU、磁盘和带宽价格，Mkcloud 的核心卖点是**线路本身**：IEPL/IPLC 属于点对点专线接入，绕开公网拥堵，端内延迟能压到很低的水位。这也是它价格比搬瓦工、Vultr 这类通用 VPS 贵出一截的根本原因。

第三方测评（liezhe、知乎及 GitHub 上的多篇评测）对它的整体评价比较一致：硬件和网络质量对得起价格，但购买门槛和售后体验有明显的取舍。

## 专线 VPS 和普通 VPS 的区别，买之前必须懂

这是整篇测评里最重要的一节。Mkcloud 官方知识库把规则写得很直白：

- 每台专线 VPS 分配 **1 个独立入口 IP + 1 个独立出口 IP**（单端双 IP）。你连入口做远程操作，VPS 里跑的业务程序自动从出口 IP 向外访问。
- **出口不接受外部连入**。公开建站、支付回调、邮件接收、游戏服务端这类需要公网入站的业务，用不了这个产品。
- 连上远程桌面后，**本地电脑的流量并不会自动走专线**。业务必须在 VPS 内运行。
- 共享套餐流量按**上行 + 下行双向统计**，超量暂停，可买流量重置或工单升级。
- 不承诺快照和备份，数据要自己管。

一句话总结：这是给“VPS 里的程序要主动去访问境外平台”的场景设计的，典型用途包括跨境电商多账号管理、独立站运营（客户端访问）、TikTok/Shopee 平台操作、量化交易对港连接这类业务。如果你要的是一台挂网站的前置服务器，直接关掉这个页面就好。

## 共享还是独享：200Mbps 和 5Mbps 哪个快

这是 Mkcloud 官方专门写过一篇文章纠正的常见误解。以沪港为例：

- 共享入门：1核 2GB、**200Mbps 峰值**、1024GB 月流量，月付 288 元；
- 独享入门：2核 4GB、**5Mbps 独享**、不限流量，月付 388 元。

共享的 200Mbps 是峰值，短时间批量上传能吃到这个速度，但不保证持续跑满，而且流量双向统计。独享的 5Mbps 数字难看，但全天 24 小时稳定保持这个速率，不限流量。如果你的任务是挂机持续传输，独享反而更合适；如果是每天集中几小时批量上货、传素材，共享档位的峰值更实用。

另外别把“独享”理解成独享 IP——两类套餐每台都是独立入口 IP + 独立出口 IP，共享和独享只区分带宽。

## 常见问题

**Mkcloud 能用来建站吗？**

不能。专线 VPS 的出口 IP 不接受公网入站，公开网站、支付回调、邮件服务器都跑不了。建站需求请选普通云服务器产品，两者不是一类东西。

**延迟数字是我到目标网站的速度吗？**

不是。官方明确说明，1~2ms、25ms 这些是“端内参考值”，即国内入口到海外出口的延迟，不等于你访问任意目标网站的全程速度，也不构成 SLA 承诺。

**流量双向计费是什么意思？**

上传和下载都算流量。500GB 月流量套餐，如果你当月上传 200GB、下载 300GB，额度就用完了。超量后服务暂停，可自助购买流量重置。

**买了之后能升级吗？**

可以，提交工单申请，是否需要迁移、能否保留 IP 以工单处理结果为准。反过来降级时，差价不退。

**没有 SLA 怎么办？**

默认套餐不含 SLA 保证。金融、高可用类业务需要在购买前通过工单确认书面服务约定，官方知识库对此写得很明确。
